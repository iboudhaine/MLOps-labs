# MLOps: End-to-End MLflow Implementation Lab

Contains a comprehensive laboratory on the MLflow lifecycle, demonstrating experiment tracking, model registry, hyperparameter tuning, and deployment across various frameworks (Scikit-Learn, TensorFlow, PySpark) and environments (Local, Databricks).

**Stack:** Python, MLflow, Scikit-Learn, TensorFlow, PySpark, Databricks.

## Lab Notebooks

1.  **Scikit-Learn:** Optimized credit card fraud detection via manual tracking and guided hyperparameter tuning.
2.  **TensorFlow:** Automated experiment tracking for MNIST digit classification.
3.  **PySpark:** Implemented distributed training pipelines for scalable fraud detection.
4.  **Deployment:** Served models via local REST API to validate real-time batch inference.
5.  **Databricks:** Benchmarked models in a cloud-native environment (Databricks).
